# 젊은 베르테르의 슬픔 프로젝트
학교 행사를 위해서 클로드를 활용한 바이브코딩으로 만든 웹이다.
[웹사이트 바로가기](https://cognitive-error.vercel.app/)

## 기획 배경
학교 행사용 체럼형 웹 서비스 제작

## 주요 기능
### 1. 인지적 오류 퀴즈
- 작품 내용과 연관된 6가지 인지적 오류 퀴즈 제공
- 모든 퀴즈의 정답을 맞추면 심리체스트 페이지로 이동하는 메커니즘

### 2. 인지 오류 심리테스트
- 총 12개의 문항으로 구성된 심리 진단 테스트
- 답변 선택지에 따라 가중치를 계산하여, 사용자에게 가장 강하게 나타나는 인지적 오류 유형을 최종 결과로 제공
- 최종 결과는 구글 시트에 저장

## 개발 방식
AI Collaboration 기반 바이브 코딩을 하였다.
